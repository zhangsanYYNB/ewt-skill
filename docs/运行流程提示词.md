# EWT360 看课自动化 · 弱模型运行提示词（2026-08 修订）

> 完整规则以 `skills/ewt360-lessons-mini/SKILL.md` 为准。本提示词只负责启动；不要复制旧版“写 ewt360-progress.md”的 recipe。

## A. 推荐方式：直接加载 mini skill

```powershell
pi -p --mode json `
  --provider <PROVIDER> `
  --model "<MODEL>" `
  --api-key "<API_KEY>" `
  --skill "skills/ewt360-lessons-mini/SKILL.md" `
  --tools "agent_browser" `
  "使用 ewt360-lessons-mini。账号=<ACCOUNT>，密码=<PASSWORD>。只测试/完成<学科>视频。登录前先勾选隐私协议；加载完全部课程后再选课；不要读写任何 progress 文件。"
```

多账户顺序运行时，每个账户都使用一条新任务消息；skill 要求新账户启动 fresh 浏览器会话、重新登录并重新发现任务，禁止沿用上个账户的 URL、计数、标题或 lessonId。

## B. 用户任务提示词

```text
使用 ewt360-lessons-mini 执行。
账号：<ACCOUNT>
密码：<PASSWORD>
学科：<语文/数学/英语/物理/化学/生物>
先做一节最短的未完成视频并验证计数 +1。
不要读写 ewt360-progress.md 或任何进度文件。
```

## C. 弱模型必须记住的五条

1. **登录顺序固定**：填账号 → 填密码 → `check .privacy__agreement input[type='checkbox']` → 验证 checked=true → 点击登录。
2. **列表必须见底**：看到“点击加载更多”就点；必须一直循环到明确看到“没有更多必学任务了”，才允许选课。
3. **关标签页要复核**：`tab list` → `tab close <非活动ID>` → 再 `tab list`。close 返回 not found 不代表没关掉，以新列表为准。禁止用 `batch --bail` 清 tab。
4. **batch 不支持 if/else**：batch 只能顺序执行；`--bail` 只能失败时停止。视频监控使用固定 wait+click，之后读取 `details.batchSteps[0]`，由下一次工具调用分支。
5. **实时页面是唯一进度源**：不要读/写共享 ledger；完成后重新打开当前账户的概览页并验证学科计数恰好 +1。
