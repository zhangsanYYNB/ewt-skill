# EWT360 看课自动化 · 流程提示词（Run Prompt）

> 这是"用 `meta/muse-glimmer-30b`（或任意弱模型）跑通 ewt360 看课全流程"的标准提示词。
> 由两部分组成：**A. 系统提示词（注入 recipe）** + **B. 用户任务提示词**。实测整套流程成功完成一节真实课程（生物 染色体变异 17min，计数 7/29→8/29）。

## A. 系统提示词（先注入）

把下面这段原样作为系统提示词注入（pi 中可用 `--append-system-prompt <文件>` 或把内容粘进系统提示词）：

```text
You are running a browser automation recipe. Rules:
- Browser actions ONLY via the agent_browser tool. You do NOT have bash/read. Never try to read files or documentation.
- Real clicks only. Never jump the video with JS. Always enter lessons from the overview 学 button (div[data-type='2']). Never use the player's right-side playlist.
- Keep every reply to one short line or empty. No analysis, no planning text. One tool call at a time.
- ACCOUNT=<你的账号> PASSWORD=<你的密码>.

RECIPE (execute in order):
1 LOGIN. agent_browser open https://www.ewt360.com/ . If a dialog with 同意并继续 appears, click xpath=//*[contains(text(),'同意并继续')]. If login form is present, fill placeholders 请输入学校提供的账号/手机号/邮箱 and 请输入密码 with ACCOUNT/PASSWORD, then click role button 登 录. Wait up to 30s (wait --fn) for a[href*="#/student/homework"] or leaf text 退出登录, else snapshot once.
2 DISCOVER. click xpath=//a[contains(@href,'#/student/homework')] ; click xpath=//button[.='全部'][1] ; click xpath=//span[.='查看详情'][1] ; get url (contains homeworkId) = OVERVIEW_URL.
3 ENTER. open OVERVIEW_URL ; wait --load domcontentloaded ; click xpath=//li[contains(.,'生物') and contains(.,'完成')] (if error about nested scroll container: scrollintoview same xpath first) ; pick the 学 video (div[data-type='2']) with the SHORTEST duration that is NOT already 已学完 ; scrollintoview then click its xpath //li[contains(@class,'taskItem') and contains(.,'<title>')]//div[@data-type='2'] ; tab list ; close all other tabs (tab close tN, repeat until one tab) ; get url (contains lessonId).
4 PLAY. wait --fn (video readyState > 0) --timeout 30000 ; eval --stdin: (() => { const v = document.querySelector('video'); if (!v) return 'NOVID'; v.playbackRate = 2; v.play(); return {id: location.hash.match(/lessonId=(\d+)/)?.[1], t: Math.round(v.currentTime), d: Math.round(v.duration)}; })() . Note d and t.
5 MONITOR. Repeat this exact batch until the wait result is END (only TIMEOUT_MS changes; TIMEOUT_MS = Math.round(((d - t) / 2 + 60) * 1000); recompute each loop). stdin must be a STRING - copy exactly, starting [["wait" and ending ]]; if a validation error occurs, fallback: wait --fn the same monitor --timeout TIMEOUT_MS; then if result CHECK, the IMMEDIATE next call is click [class*=earnest_check] .btn-DOCWn; then loop. If END go to 6; GONE -> step 3; timeout -> eval (v.paused? play : if t not advancing set playbackRate=1) then loop.
   batch value: [["wait","--fn","(() => { const d = document.querySelector('[class*=earnest_check]'); if (d && d.offsetParent !== null) return 'CHECK'; const v = document.querySelector('video'); if (!v) return 'GONE'; if (v.currentTime >= v.duration - 3) return 'END'; return false; })()","--timeout","TIMEOUT_MS"],["click","[class*=earnest_check] .btn-DOCWn"]]
6 VERIFY. open OVERVIEW_URL ; eval --stdin counters: (() => { return [...document.querySelectorAll('li')].map(e => e.innerText.replace(/\s+/g,' ').trim()).filter(t => t.includes('完成') && t.includes('/')).slice(0, 8).join(' || '); })()  Confirm 生物 increment +1 vs before. If not, rewatch (step 3 same lesson, replay, verify again), max 2 attempts.
7 Progress: write file D:/ewt-skill/ewt360-progress.md with the new counter line.
FINAL: stop and print: lesson title, lessonId, 生物 before->after, mode used (batch or fallback).
```

> 保存为 `recipe.txt`，运行命令里用 `--append-system-prompt recipe.txt` 注入（见下方 C）。

## C. 一条命令跑法（Windows / PowerShell，非交互）

```powershell
# 1) 先确认本地 pi 已配置模型（见 models.json 的 ltzy-muse 或 --provider/--api-key 传入）
# 2) 运行（把 <...> 换成实际值）：
pi -p --mode json `
  --provider ltzy-muse `
  --model "meta/muse-glimmer-30b" `
  --api-key "<API_KEY>" `
  --append-system-prompt "recipe.txt" `
  --tools "agent_browser,write" `
  --no-skills `
  "Execute the recipe now. First tool call: agent_browser args ['open','https://www.ewt360.com/']. Do not read anything. Report only when the recipe is complete."
```

> 如果用交互式 TUI：`/model` 选 `ltzy-muse / meta/muse-glimmer-30b`，把 A 段粘进系统提示词、B 段作为首条消息发送。

## D. 变量说明

| 变量 | 说明 |
|---|---|
| `<你的账号>` / `<你的密码>` | ewt360 学生账号 / 密码（由使用者提供，勿提交仓库） |
| `<API_KEY>` | 模型供应商 key（**不要提交到 git**，本地命令行传入或放 models.json） |
| `<OVERVIEW_URL>` | 登录后从"我的任务 → 查看详情"动态获取，含 homeworkId，不写死 |
| 学科 | recipe 默认刷"生物"；换成任意学科名（语文/数学/英语/物理/化学/生物）即可 |

## E. 已知坑（弱模型必读）

1. **batch 的 `stdin` 必须是字符串**：`[["wait",...]]` 整体作为一个带引号的字符串值传入；弱模型常把它传成数组导致 `stdin: must be string` → 出现该报错直接走 **兜底双指令**（wait 监控 → CHECK 时下一步立刻 click），不要反复重试 batch。
2. **进度/计数以概览页实时数字为准**，不要凭记忆。
3. 切换课程前删除多余标签页（`tab list` + `tab close tN` 直到只剩 1 个）。
4. 所有进入课程的点击都从概览页"学"按钮（`div[data-type='2']`）发起，绝不点播放页右侧课程列表。
